# 주제 팩 편집 메모

이 파일은 콘텐츠 유지보수를 위한 메모입니다. 모든 주제는 실제 법령·학칙·시행 중 정책을 설명하는 자료가 아니라 **토론을 위한 가상 제안**입니다. 사건 속 인물·학교·지역과 상황도 모두 가상입니다.

- 5개 주제마다 전용 역할 6개, 역할별 관점 카드 3장, 사건 1개, 대응 선택지 4개, 교차 질문 6개를 제공합니다.
- 모든 카드는 `type: perspective`, `label: 토론용 관점 카드`, `sourceStatus: discussion_only`로 표시합니다. 외부 사실의 근거 카드로 취급하거나 카드의 문장을 검증된 통계·법률로 인용하지 않습니다.
- `status: editorial_reviewed`는 논점·표현·구성의 내부 검토 상태입니다. 외부 자료의 사실 확인을 의미하지 않습니다. 검증된 외부 출처가 없으므로 `sources`는 빈 배열입니다.
- 역할의 `stance`는 이 가상 제안에 대한 역할 배정용 대략적인 방향입니다. 해당 직업·집단 전체의 실제 성향이나 참가자의 실제 신념을 뜻하지 않습니다. 역할은 목표와 우선 가치를 일관되게 설명하면 여러 결론을 제시할 수 있습니다.
- 대응 선택지는 정답·오답이 없습니다. 서로 다른 우선순위와 절차를 비교하도록 구성했습니다. 효과나 비용을 수치로 단정하지 않습니다.
- 데이터의 기준은 `backend/app/content/topics/*.json`이며 `topics.json`은 같은 내용의 프런트엔드 로컬 체험용 배열입니다. 콘텐츠를 수정하면 양쪽을 함께 갱신하고 `version`도 올립니다. 서버가 게임 시작 시 고정한 주제와 버전을 실제 방에서 사용합니다.
- 역할·카드·사건·선택지 ID는 모두 해당 `topicId` 접두사로 시작합니다. 주제를 추가할 때도 이 규칙을 유지하여 다른 주제 데이터가 섞였는지 검사할 수 있게 합니다.
- 참가자의 실제 의견 변화는 콘텐츠의 정답이나 성과 기준이 아닙니다. 서로의 우선 가치를 정확히 설명하고 동의하지 않는 점도 존중하며 표현하도록 구성합니다.
